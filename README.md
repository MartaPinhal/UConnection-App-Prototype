# UConnection — University Student App Prototype

UConnection is a UX/UI application prototype designed to improve connection and interaction between university students.

## About the Project

The project explored how a digital platform could support university students by creating a centralised space for connecting with other students and accessing relevant university-related interactions and information.

The prototype was developed with a user-centred approach, focusing on creating a clear and intuitive digital experience for students.

## Objectives

- Improve connection between university students
- Explore the structure and organisation of a student-focused digital platform
- Design intuitive user flows and interactions
- Apply UX/UI and information architecture principles
- Develop and test a functional application concept

## Key Areas

- UX/UI Design
- User-Centred Design
- Information Architecture
- User Flows
- Interaction Design
- App Prototyping

## Project Type

Academic project developed during my Bachelor's degree in Information Science at the University of Porto.
